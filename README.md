# Joyce’s portfolio

A responsive student portfolio built entirely with HTML and CSS. No JavaScript is used.

## Edit your website

- `index.html`: change the text, project cards, and contact placeholders.
- `styles.css`: change the colors, spacing, and layouts.
- `joyce-image.jpg`: the image you supplied, copied without alteration.

Projects are clearly labeled as future ideas. Contact rows are placeholders, not fake working links. The project cards use HTML `<details>` elements, so they can open and close without JavaScript.

To view the site locally, open `index.html` in a browser, or run:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then visit http://127.0.0.1:4173 . Fonts use Google Fonts when online and fall back to built-in fonts otherwise.

The design received a second pass for typography, About-section emphasis, image framing, card alignment, tablet columns, mobile navigation, and touch targets.
